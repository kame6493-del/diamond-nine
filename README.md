# がっこう野球部ものがたり

弱小高校野球部の監督として、週単位で練習、試合、学校施設、スカウトを進めるブラウザ向け育成シミュレーションMVPです。

## 起動方法

```bash
cd "C:\Users\yuichi1\Downloads\chatgpt\栄冠ナインみたいなゲーム"
npm install
npm run dev
```

表示されたURLをブラウザで開くと遊べます。`C:\WINDOWS\system32` など別フォルダで実行すると `package.json` が見つからないため、必ず上の作業フォルダへ移動してから実行してください。PowerShellで `npm` の実行ポリシーエラーが出る場合は、次のように `npm.cmd` を使ってください。

```bash
npm.cmd install
npm.cmd run dev
```

作業フォルダへ移動するところからまとめて実行する場合:

```bash
cd "C:\Users\yuichi1\Downloads\chatgpt\栄冠ナインみたいなゲーム"
npm.cmd install
npm.cmd run dev
```

この作業環境のようにnpmの標準キャッシュへ書き込めない場合は、作業フォルダ内キャッシュを使えます。

```bash
npm.cmd install --cache .npm-cache
```

## 年間スケジュール

1年は4月から翌年3月までで、1か月を4週として進みます。練習を1回選ぶと週が進み、天気、疲労回復、年間イベント、大会予定が更新されます。

- 4月: 新入生加入 / 春大会
- 6月: 夏大会前の追い込み
- 7月: 夏の地区大会
- 8月: 全国大会、または夏合宿
- 9月: 3年生引退
- 10月: 秋大会
- 12月: 冬トレ
- 1月: 初詣
- 2月: スカウト強化
- 3月: 卒業 / 新年度準備

## 大会機能

練習試合とは別に、春大会、夏の地区大会、全国大会、秋大会があります。大会週に練習を終えると公式戦が発生し、勝つと次の週に次戦へ進み、負けると大会終了です。勝ち上がるほど相手校ランクが上がり、大会結果は試合履歴とイベントログへ残ります。

夏の地区大会を勝ち抜くと8月の全国大会へ進みます。全国大会へ届かなかった年は、8月に夏合宿が発生します。

## 試合中の采配

試合は1イニング半ごとに進行します。画面にはデフォルメ野球中継風のグラウンド、現在/次攻撃の打者、現在投手、スコア、ベンチサイン、実況ログが表示されます。監督は限られた采配回数と選手交代枠の中で、状況に合わせて作戦を選べます。

- おまかせ: 通常進行。采配回数を消費しません
- 強攻策: 攻撃時に複数得点を狙います
- 送りバント: 攻撃時に堅く1点を取りに行きます
- 盗塁: 走力と信頼度で相手を揺さぶります
- 代打: 控え選手を打席へ送ります
- 守備位置変更: 守備時に失点を抑えに行きます
- 継投/声かけ: 投手を落ち着かせ、終盤やピンチに備えます
- 投手交代: 控え投手へ継投します

作戦成功率には、選手の信頼度、性格、やる気、データ室レベルが影響します。試合後はスコア、活躍選手、報酬、評判変化、実況ログが結果画面に残ります。

## 編成

試合画面では、試合前に打順、先発投手、控え投手、主将を設定できます。編成はlocalStorageに保存されます。年度進行や卒業で選手が入れ替わった場合は、古い編成を読み込んでも残っている選手を優先し、不足分を自動補完します。

## 新入生・卒業

毎年4月に新入生が加入します。学校評判、スカウト室レベル、前年成績が高いほど能力の高い選手が来やすくなります。低確率で、天才肌、怪物投手、俊足型、守備職人のような注目株も登場します。

3年生は夏大会終了後に引退し、後輩へ信頼度ボーナスを残します。3月には卒業ログが記録され、下級生が進級して新年度へ進みます。

## 特殊能力効果

- チャンス強い: 試合中の得点力を少し上げます
- 粘り打ち: 攻撃の継続力を上げます
- 盗塁上手: 走力評価を上げます
- 堅守: 守備力評価を上げます
- 強肩: 肩力評価を上げます
- 逆境: 負けている終盤の攻撃を後押しします
- ムード○: チーム平均やる気を底上げします
- 尻上がり: 投手の後半失点率を下げます
- ピンチ強い: 投手力を上げます

## バランス調整

練習の成長量は控えめにし、疲労が高いほど成長効率が落ち、怪我や不調が起きやすくなっています。休養は疲労と怪我回復、ミーティングは信頼度とやる気の回復に強く、試合前に選ぶ意味が出るように調整しています。

## データ保存

localStorageに次のキーで保存します。

- `gameState`
- `players`
- `teamLineup`
- `facilities`
- `scoutingCandidates`
- `matchHistory`
- `eventLog`

## 主なディレクトリ

```text
src/
  data/        初期選手、練習メニュー、イベント、施設
  logic/       練習、試合、イベント、週進行、保存、ランク計算
  types/       GameState、Playerなどの型定義
  components/ 画面とUI部品
  constants/  画像アセットなどの共通定数
  styles/      TailwindのグローバルCSS
```
