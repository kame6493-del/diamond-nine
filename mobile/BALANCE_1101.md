# バランスの見直し（2026-11-01 夜・Android 34 / 1.4.1）

持ち主が 11/1 夜に遊んで言ったこと。

- 「余りにも大盤振る舞い過ぎて、速攻でクリアできてしまいそう。課金圧がちゃんとなるように。チームを徐々に強くしていく過程が余りにもなさすぎる」
- 「課金圧が強すぎて遊べなさすぎるのもあれなので、行動力要素いらないかも」
- 「今の大盤振る舞い過ぎて速攻で強くなりすぎるのはなんとかして、良い感じのバランスに」
- 「自分はある程度儲けたい」（目安: 無課金 7〜10年目・プレミアムパス 4〜6年目・ポイント購入 2〜4年目に優勝争い。無課金でも時間をかければ届く）
- 10/29 にパスと 30万pt を買った人がいた頃の版（vc25 / vc26）の課金圧を上限の目安に。

守ったこと: 10連・まとめて引くは無し。進めるのは「1年進める」だけ。提供割合は国内全員同じ（補強ブースト・野手寄せは戻していない）。海外2%・30回ごとの確定・ドラフトのルーキー枠はそのまま。スカウト1回 3,000pt・覚醒の値段・ポイントのパック6つの中身と値段は変えていない（持っているポイントの価値を下げない）。偽の期限・確率の見せかけ・払わないと越えられない壁は無い。

## 何を変えたか

1. 行動力をやめた。「1年進める」はいつでも押せる。上の札・回復の欄・ドリンクの配布・満タンの通知を出さない（stamina.ts の STAMINA_ENABLED=false。仕組みのコードと端末の記録は残す）。
   - 精算: 上限（100）を超えて持っていた行動力は 1あたり 40pt（満タン回復 4,000pt で＋100 の値段）、持っていた回復ドリンクは1本 1,200pt（＋30 ぶん）で、一度だけポイントに替えて返す。上限 30,000pt。起動した時に「行動力の仕組みをなくしました。…＋◯pt に替えました」と出る。ポイントで回復して既に使った分は、その年を進めるのに使い終わっているので返す物は無い。
   - 判断: 行動力は「待たせて払わせる」仕組みで、持ち主の「遊べなさすぎる」に当たる。選手の疲れ（試合ごとの調子・先発の間隔）は野球の作戦なので触っていない。それはポイントで回復する物ではない。
2. 1年ごとに入るポイントを 10/28（vc25）の水準へ戻した。行動力が無いと1年を何回でも進められるので、1年あたりの量で決めた。
3. 年ごとの成長と衰えを足した。1年終えるたびに持っている選手全員が1つ年を取り、若手は伸び、30代半ばから衰える（development.ts growOneYear）。
4. はじめに選ぶ3人を 総合85以上 → 総合74〜82 にした。
5. プレミアムパスを「毎年効く」形にした。
6. あと一歩で優勝を逃した年だけ、結果の画面に補強の道（弱い所2人と、押すと開くポイント購入）を出す。
7. はじめての購入だけの1回限りのパックを足した（¥480 で 30,000pt）。
8. 動画を見てスカウト1回は 1日10回 → 2回。無課金の人の道として残す。

# vc35 / 1.4.2（2026-11-02）年ごとの成長と衰えをやめた

持ち主が 11/2 朝に言ったこと: 「選手が年ごとに衰えたり成長させるのは辞めて」。vc34 は同じ日の 07:58 に製品版に出したばかり。

## 変えたこと

1. 年を取っても能力は変わらない。development.ts の YEARLY_GROWTH_ENABLED=false で growOneYear は何もしない（careerGrowth・grownSeason は増えない）。
2. 選手の詳細の「年ごとの成長 ＋◯（来年 伸びる／衰える）」、次のシーズンの始まりの「成長: ◯◯ ＋4 ・衰え: △△ −2」、あと一歩の欄の「若い選手は来年も伸びます。」、遊び方ガイドの「年ごとの成長」を消した。
3. 年齢は vc33 までと同じ表示（2026年の年齢）に戻した。vc34 の「チームで過ごした年数を足した年齢」はやめた。
4. 強くなる道がスカウトと覚醒だけになったので、シーズン完走のポイントを 600 → 9,600、新しく始める人のはじめの選手の上限を 打者52・先発57・救援54 → 59・64・61 にした（下の表で決めた）。

変えていない物: スカウト1回 3,000pt、提供割合（国内全員同じ・海外2%・30回確定）、パックの中身と値段、はじめてのパック、覚醒の値段、パスの中身（毎日1,000・シーズンごと6,000・試合1.5倍）。10連・補強ブースト・行動力は入れていない。

## vc34 のセーブ（成長・衰えが済んだ人）

- セーブはそのまま読める。careerGrowth の欄は捨てずに読み、検査も前と同じ。
- 伸びた分（＋）はそのまま残し、衰えた分（−）は戻す（growthBonus を 0 未満にしない）。遊ぶ人が損をしない側。vc34 は今朝製品版に出したがまだ審査中なので、成長が付いたセーブを持つのは alpha のテスターくらい。
- これからは増えも減りもしない。年齢の表示は元の年齢に戻る。

- 打席の結果を見せた瞬間に、打者の札（今季 打率・本塁打・打点、今日の成績）と投手の札（今季 防御率・投球回・奪三振・自責、今日の成績）の数が変わる。成績表（途中・試合後）の「今季打率」「今季防御率」、相手チーム・選手交代の画面の今季の数も同じ数。監督して戦う・おまかせで観るの両方。
- 今季の数 = 試合の直前の表（レギュラーシーズン。短期決戦の試合は短期決戦の表）＋この試合のここまで（src/pro/live-stats.ts）。試合の後にシーズンへ入る数は直前の表に試合の成績表を足した物なので、最後に必ず一致し、二重には数えない（試験で確かめた）。開幕戦は今季の表が空なので「---→.000」のように始まる。
- 防御率は今までどおり自責点（engine.ts の era と同じ 自責×27÷アウト数）。投手の数はゲームに自責点しか記録が無いので、札の「失点」を「自責」と書き直した（タイブレークの走者などは自責に入らない）。投球回0の時の防御率は「-」（前は「-.--」）。
- 見せ方: 変わった数を1.6秒ほど光らせる。良くなった（打率が上がる・防御率が下がる・本塁打/打点/奪三振/投球回が増える）は緑、悪くなった（打率が下がる・防御率が上がる・自責が増える）は赤。打率と防御率は「.273→.304」「0.00→13.50」の形、数は新しい数だけ光る。今日の成績は薄い金色で光る。
- 札は画面の下にあり、小さい画面では操作の欄に隠れるので、グラウンドの上の端にも小さく出す（左に打者の打率、動かない時は打点。右に投手の防御率、動かない時は奪三振）。次の打者が打席に入ると消える。
- 結果を見せた打者・投手は、次の打席が始まるまで札に残す（前は結果と同時に次の打者に替わって、変わった数が見えなかった）。成績が変わった時だけ、次の打席までの間を少し長くした（1倍 +0.4秒・2倍 +0.2秒・4倍 +0.1秒）。
- 前から、試合の計算は先の打席まで進んでいて、札の「今日」の数が結果を見せる前に変わっていた（試合の始まりで「1打数0安打」など）。見せた時の「この試合の成績」を写して使うようにしたので、数は結果を見せた瞬間に変わる。倍速・「次の打席へ」でも同じ写しなので、数は正しく追いつく。「試合終了まで」・途中から開き直した時は光らせない（数は最後まで合う）。
