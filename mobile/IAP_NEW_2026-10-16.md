# Play Console に登録する新しいアプリ内アイテム（2026-10-16）

この回は Play Console に触っていない。下の6つを「1回限りの購入アイテム（消耗型）」として登録すると、アプリのスカウト画面・設定画面の「ポイント購入」に価格が出て買えるようになる。登録が無い間は「販売準備中」で押せない（ブラウザ版はいつも「アプリ版で使えます」）。

コードの置き場所: src/pro/point-products.ts の pointPacks（ID・ポイント・税込価格）。購入の処理は mobile/monetize.ts の buyPack / refreshPacks。

- 説明文（全商品共通の型）: 「スカウト（選手カードをランダムに1枚獲得）と覚醒に使えるポイントです。スカウト1回3,000pt・10連30,000pt。提供割合はスカウト画面の『提供割合』で確認できます。」
- 価格は Google Play で日本円を直接入力できる額（¥160〜¥10,000）。他の国の価格は Play の自動換算でよい。
- 種類は「1回限りの購入」。アプリ側は付与のあとに consumePurchase で消費するので、同じ商品を何度でも買える。
- 既存の商品はそのまま: premium_pass（非消耗型・¥480）。2026-09-25 の案 points_3000 / points_13000 / points_28000 は一度も登録・販売していない。別の中身で使い回さないよう、ID は欠番として残す（登録もしない）。

## プレミアムパスの説明文を直す（登録済みの premium_pass）

中身を変えたので、Play と App Store Connect の説明文を次へ差し替える。

- 旧: 全画面広告なし・試合で獲得するポイント 2 倍・毎日ログインで 1,000pt
- 新: 全画面広告なし・試合で獲得するポイント 1.5 倍・毎日ログインで 500pt

## 登録のあとに確かめること

1. ライセンステスターで ¥160 を買い、スカウト画面に「ポイント購入 ＋3,000 pt」が出て所持が増えること。
2. 購入の直後にアプリを落とし、開き直したときに1回だけ付与されること（端末の台帳 diamond-nine-iap-ledger で二重よけ）。
3. 「15歳以下」を選んで ¥10,000 を押すと止まること。「16〜17歳」で ¥5,000 を2回目に押すと止まること。
4. 保留（コンビニ払いなど）のときは付与されず、支払いが済んだあと次に開いたときに付与されること。
5. データセーフティの「購入履歴」を「収集する（アプリの機能）」に直すかを確認する（Play の購入情報は Google が処理、アプリは端末に記録するだけ）。

## まだ残っていること（販売前に決める）

- サーバーでの購入の検証は無い。端末の中だけで付与している。返金されたポイントは取り戻せない（Play の Voided Purchases API を使う仕組みが無い）。少額のうちはこのままで、売上が出てきたら検証サーバーを足す。
- 買ったポイントはセーブに入るので、完全リセット・アプリ削除で消える。購入画面にそのことを書いてある。書き出したセーブを読み込むと増やせてしまうが、一人用で他人に影響しないため止めていない。
- 特定商取引法に基づく表記と、資金決済法（前払式支払手段・自家型）の表示のページを用意する。ポイントに有効期限は付けていない。未使用残高が基準日（3月末・9月末）に1,000万円を超えたら届出と供託が必要になるので、売上がそこへ近づいたら有効期限（180日）を付けるか届出をする。
- iOS で同じパックを売る場合は App Store Connect にも同じ ID で登録する（コードは iOS でも同じ処理）。
