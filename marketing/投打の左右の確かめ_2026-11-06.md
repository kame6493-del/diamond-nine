# 投打の左右の確かめ 2026-11-06 (DIAMOND NINE 1.5.1 / vc44)

持ち主「外国人選手、メジャーリーガーの右左、なんかおかしい気がするから、それちゃんとして」。

## 何がおかしかったか
- 海外リーグの相手の選手 1362人(src/pro/mlb-opponents2026.json)には、投打の左右のデータが入っていなかった。
- src/pro/mlb-opponents.ts が、名鑑のカード15人以外を全員「右投右打」(bats '右' / throws '右')で埋めていた。ランダムではなく、決まった値。
- 画面(選手の詳細の「右投右打」)・打席の向き(field-sim.ts の batSide)・左右の相性(wiki-traits.ts)が、どれもこの値を使うので、左打者も右の打席に立っていた。

## 照らした出典
- MLB: MLB Advanced Media 公式の Stats API https://statsapi.mlb.com/api/v1/people?personIds=… の batSide / pitchHand (MLB.com の選手名鑑と同じ値)。取得 2026-11-06。1363人すべて取れた。保存先 src/pro/mlb-hands2026.json、取り方 scripts/fetch-mlb-hands.mjs。
- NPB(日本人・外国人とも): NPB 公式 https://npb.jp/bis/teams/rst_*.html (2026-09-20 の登録名簿)と各選手のページ https://npb.jp/bis/players/*.html の「投打」。

## 結果
- 直した人数: MLB の相手の選手 543人(下の表)。残りの 819人は公式も右投右打で、変わらない。
- 自分のチームに入る MLB のカード15人: 公式と全員同じ(直しなし)。
- NPB の外国人選手 109人: npb.jp の各選手のページと1人ずつ照らして、食い違い 0人。
- NPB の 2026 年の登録選手 1,067人: 名簿の値を使っていて、成績の表の値とも食い違い 0人。打つ側が入っていない選手は 0人。
